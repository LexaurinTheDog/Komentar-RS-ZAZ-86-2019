# Коментар Закона о агенцијском запошљавању

Коментар српског прописа: **Закон о агенцијском запошљавању** („Службени гласник РС”, број 86/2019). Обухвата **41 јединицу** (чланове 1–41) у 2 поглавља коментара; уз сваки члан дат је дословни текст одредбе и коментар.

Стање прописа према: редакцијски пречишћен текст Правно-информационог система Републике Србије (према подацима извора без накнадних измена; једина наведена објава је „Службени гласник РС”, број 86/2019), преузет 2. октобра 2026.

## Садржај

Види [INDEX.md](INDEX.md). Опис метода у [00-uvod.md](00-uvod.md).

1. Предмет и дефиниције, услови за рад Агенције и услови за уступање запослених (чл. 1–17)
2. Услови рада уступљеног запосленог, обавезе Агенције и послодавца корисника, колективна права, накнада штете, надзор, казнене, прелазне и завршне одредбе (чл. 18–41)
